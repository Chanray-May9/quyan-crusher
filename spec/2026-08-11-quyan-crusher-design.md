# 蛆言粉碎机 · 设计文档

日期：2026-08-11

## 一句话

中文互联网男拳话术的档案馆 + 反击工具箱。不是为了跟谁讨论，是为了让人在被噎住的那一秒有话可说。

## 立场与边界

**打什么**：话术、行为、逻辑、以及支撑它们的那套系统。重点打说话难听的中年顺直男——酒桌劝酒、爹味说教、辈分压人、荤段子当幽默、拿女儿撑权威。火力开到最大档，脏话不留，不做「理性讨论」的姿态。

**不打什么**：不写「男的天生是牲口 / 该死」这类血统论，不写号召暴力的内容。原因是战术性的而非道德性的——那种句子恰好是对面最想截图的素材，一张图就能把整个站定性成「极端」，从而让 54 条有理有据的拆解一起作废。精准解剖比骂血统疼得多，也难反驳得多。

## 内容架构

**病种分类（13 类，54 条）**

爹味说教型 · 贞操审判型 · 受害者有罪型 · 生育绑架型 · 外貌规训型 · 伪中立型 · 打拳污名型 · 情绪贬用型 · 家务隐形型 · 职场规训型 · 越界不认账型 · 婚俗物化型 · 中年爹味重灾区

**每条的固定结构**

| 字段 | 作用 |
|---|---|
| `quote` | 他说的原话 |
| `decode` | 他真正的意思是（一句话，最狠的一击） |
| `analysis` | 拆解：这句话在干什么、为什么成立、他图什么 |
| `cold` / `hot` / `table` | 三档反击 |
| `patterns` | 检测器关键词，与条目共用同一份数据 |

**三档火力的使用场景**

- **冷刀**：需要留脸的场合（办公室、亲戚桌）。不带情绪，只把逻辑钉死
- **热锅**：朋友、伴侣之间。带情绪，但仍在对话框架内
- **掀桌**：不打算再见他的时候。脏，因为对面先脏的

分档的意义在于：现实里大部分场合你无法掀桌，如果只提供最狠的一档，这个工具在 90% 的时刻是不可用的。

## 八个板块

1. **蛆言图鉴** —— 核心档案库，搜索 + 病种筛选，卡片展开
2. **蛆言检测器** —— 纯前端规则引擎，与图鉴共用 `patterns`，出蛆言指数 0–100
3. **弹药库** —— 30 条通用回击，按档筛选，一键复制
4. **爹味 Bingo** —— 60 句素材抽 5×5，连线文案
5. **蛆言现场** —— 匿名投稿墙，唯一的后端功能
6. **数字不哄你** —— 15 条硬数据，全部带原始链接
7. **黑话辞典** —— 20 词条，把命名权拿回来
8. **今日一蛆** —— 首页 hero，按日期取模，一天固定一条

## 技术架构

**零构建**。纯 HTML/CSS/JS + JSON 数据，没有打包器、没有依赖、没有 CI。

这个选择是为了满足一个具体需求：同一份 `docs/` 目录要同时喂给 Cloudflare Pages 和 GitHub Pages。有构建步骤的话两个平台需要各自配一套流水线，迟早跑偏。零构建则保证两边字节级一致。

**前后端边界**

- 检测器、Bingo、图鉴、辞典、数据 —— 全部纯前端，不联网。检测器尤其重要：用户粘进去的往往是伴侣或同事的真实聊天记录，不能上传
- 投稿墙 —— Worker + D1。两份前端通过 `config.js` 的 `API_BASE` 指向同一个 Worker，因此墙上内容两边一致

**数据即内容**。所有文案在 `docs/assets/data/*.json`。加一条蛆言只需往 `entries.json` 加一个对象，检测器和分类筛选器会自动接上，不用碰代码。

## 后端设计：不审核

投稿墙不做内容审核。脏话、辱骂、火气一个字不过滤。

只保留两道纯技术管道：

1. **频率限制** —— 25 秒冷却 / 每 IP 每天 30 条。防机器人刷屏，与言论内容无关
2. **个人信息拦截** —— 手机号、身份证、邮箱、银行卡、车牌、详细住址、社交账号

第二条不是审查，是防止这面墙变成挂人工具。这个风险是具体的：挂人的法律后果落在站长头上，不落在被挂的人头上。

IP 只以 SHA-256 加盐后的前 12 字节存储，用于频率控制，不可逆。

另设一个 `DELETE /api/posts/:id` 接口，需要 `ADMIN_TOKEN`，用于法律层面必须处理的内容。

## 视觉

大字报 / 病历纸。纸色底 `#f2eee4`、血红 `#cf1220`、零圆角、粗黑标题、红色实心色块、硬投影、纸纹覆层。浅色是为了长时间阅读不刺眼，攻击力靠对比度和红色实心块撑住，不靠暗背景。

刻意避开的：柔和粉紫的「女性向」配色、圆角卡片、渐变按钮、emoji 装饰——这些视觉语言本身就带着一种「请温柔地看待我们的诉求」的姿态，与内容矛盾。

## 文案原则

短句。不用「总而言之」「值得注意的是」「让我们一起」。不堆 emoji。不加「理性讨论」免责声明。不在结尾问「你觉得呢」。

读起来要像一个真的被气到的人在打字，而不是像一份报告。

## 数据纪律

所有数字必须有可点击的原始出处。一个假数字就够对面否定整个站，所以这部分不能松。已核准来源：国家统计局 2018 年全国时间利用调查、智联招聘 2024 中国女性职场现状调查报告、第三/第四期中国妇女社会地位调查、南方都市报 320 份涉家暴判决书统计。

## 部署

- 前端 A：`wrangler pages deploy docs --project-name=quyan-crusher`
- 前端 B：GitHub 仓库 Settings → Pages → main 分支 `/docs`
- 源码：推送到 GitHub
