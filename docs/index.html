// 这站是干什么的

不是为了跟谁「讨论」。讨论的前提是双方都讲道理，而你我都清楚，说出那些话的人从一开始就没打算讲道理——他们只是习惯了说完之后没人回嘴。

所以这里只做三件事：把话记下来，把逻辑拆开，把回击备好。

拆解不是为了说服他。是为了让你在那一秒不再懵——很多时候你不是不会反驳，你只是被那句话的无耻程度当场噎住了，等回过神来场早就散了。这里就是提前把神回过来。

火力分三档，你自己挑：冷刀用在需要留脸的场合（办公室、亲戚桌），热锅用在朋友和伴侣之间，掀桌用在你已经不打算再见他的时候。第三档很脏，因为对面先脏的。

最后一句：你不是敏感，你不是玻璃心，你不是开不起玩笑。你只是终于听清了。
